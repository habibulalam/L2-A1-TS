# TypeScript Assignment

## Assignment Overview

This repository contains my TypeScript assignment solutions. In this assignment, I practiced different TypeScript concepts and learned how to use them in practical examples.

The assignment includes two blog posts about TypeScript concepts and a `solutions.ts` file containing the solutions to the given programming problems.

## Assignment Contents

### 1. Blog Posts

- [Type vs Interface in TypeScript](./type-vs-interface.md)  
  Explains the main differences between `type` and `interface`, their features, and when to use them.

- [Access Modifiers in TypeScript](./access-modifiers.md)  
  Explains `public`, `private`, `protected`, and `readonly` with examples in TypeScript OOP.

### 2. TypeScript Solutions

- [`solutions.ts`](./solutions.ts)  
  Contains the solutions to the TypeScript programming problems, including functions, union types, tuples, generics, interfaces, classes, and asynchronous functions.
